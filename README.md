# 移动端语言听写练习工具（sologsb-1029）

面向手机使用的听写练习应用，包含学习端和教师反馈视图。课程、未提交答案、练习进度、逐词结果与反馈均保存在浏览器本地，可离线继续已下载课程。

## 功能

- 课程库：按课程和课节展示难度、句数、预计时长与下载状态。
- 离线课程：可切换课节下载标记；首次访问后由 Service Worker 缓存应用壳，断网重开仍可进入已下载课程并继续编辑。
- 听写流程：调用浏览器语音合成播放完整句子，输入答案后按句导航或整课提交。
- 逐词判错：使用词级序列比对识别拼写、漏词和多余词，并生成单句与整课得分。
- 错误复核：错误词可单独重听；可选择起止词重听指定片段；可为每个错误选择类别并记录原因。
- 教师反馈：教师视图可选择学生作答并写入反馈，反馈会回显在学习记录中。
- 进度恢复：保存每句答案和当前句，刷新、切换应用或手机旋转后可恢复。
- 设备交接（离线多设备合并）：
  - 课程库首页「设备交接」面板可生成/粘贴交接码，交接码是带课程指纹的累计改动日志，每项改动带**设备号 + 单调序号**，重复导入按 `(设备号, 序号)` 幂等去重，不会重复生效。
  - 不同句子、不同作答自动并合；同一句草稿、同一错词分类或同一条教师反馈两边都改过（相对共同基线）时，导入预览会逐条列出冲突，显示两边设备名与内容，人工选择后才写入。
  - 交接不是整份覆盖：晚保存的一方不会带走另一方的答案、错因或反馈。
  - 导入先在副本上预演，再根据 `navigator.storage.estimate()` 做容量预检；本机容量不足直接拒绝合并并保留原记录，写入失败同样回滚，清理空间后可用同一交接码重试。
  - 课程按句子内容计算指纹；课程版本变化后，受影响作答里的错词用保存的答案**失效重算**（旧人工分类不沿用），跨设备带来的过期错因分类直接失效；引用不到原句的交接记录会让整单**停止写入**。
  - v1 本地数据升级到 v2 时兼容原有答案、进度、分类与反馈；应用升级后启动也会对内置课程做同样的对账。
- 可访问性：支持浅色/深色模式、五档字号区间、触控尺寸、键盘提交和减少动态效果偏好。
- 记录导出：将练习历史、逐词结果、错误分类、原因和教师反馈导出为 JSON（与结果页、教师复核读取同一份合并后的状态）。

## 技术栈

- Vue 3
- TypeScript 5
- Varlet UI
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`，适合通过局域网在手机浏览器中测试。宿主机正式端口按根目录 `docker-compose.yml` 映射为 `10029:80`。

## 类型检查、测试与生产构建

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1029 .
docker run --rm -p 10029:80 sologsb-1029
```

最终镜像仅包含 nginx 和静态构建产物，nginx 监听容器 `80`。

## 数据说明

浏览器存储键沿用 `sologsb-1029-dictation-state-v1`，内部结构已升级到 `schemaVersion: 2`（v1 数据自动迁移）。状态中除原有的课程、作答、进度外，还包含设备号、各设备序号水位、课程句子指纹与累计交接改动日志。导出文件为 UTF-8 JSON，可用于后续学习分析；交接码为 `ECHOSTEP2:` 前缀加 base64，内容是自描述 JSON，便于人工传递（聊天/扫码/文件均可）。
